# Spring über Adrian

Ein kleines Pixel-Spiel fürs Handy: Ein Katzosaurus (halb Katze, halb Dinosaurier) läuft los und springt über Adrian.

**Spielen:** `index.html` im Browser öffnen, am besten auf dem Handy. Es braucht keinen Build-Schritt und keine Abhängigkeiten.

## Steuerung

| Handy | Tastatur | Aktion |
| --- | --- | --- |
| Tippen | Leertaste / Pfeil hoch | Springen |
| Gedrückt halten | Taste halten | Höher springen |
| Nach unten wischen | Pfeil runter | Schneller landen |
| | P / Esc | Pause |

## Was passiert

- Adrian taucht in mehreren Varianten auf: normal, jubelnd (größer), als Doppel-Adrian und ab etwa 320 Punkten fliegend (tief: drüber springen, hoch: drunter durchlaufen).
- Das Tempo steigt mit den Punkten, und der Himmel wechselt zwischen Tag, Abend und Nacht.
- Rekord und Ton-Einstellung werden lokal im Browser gespeichert.

## Online stellen

Mit GitHub Pages: in den Repository-Einstellungen unter *Pages* den Branch mit `index.html` auswählen.
